I'm Mert, also known as **physic**. I build products end to end: the web app, the API behind it, and the desktop and mobile clients on top. Most of that work goes into **[Anysola](https://www.anysola.com)**, a growing set of apps, self-hosted tools and a terminal coding agent.

Ask me about React, Next.js, Node.js, Electron or Tauri. I care about clean code, fast feedback and shipping things people actually use.

## Building now

| Project | What it does | Stack |
| :-- | :-- | :-- |
| **[Anysola Code](https://github.com/Anysola/code)** | A coding agent for your terminal, based on OpenCode. [anysola.com/code](https://www.anysola.com/code) | TypeScript |
| **[code-action](https://github.com/Anysola/code-action)** | Anysola Code on GitHub Actions: pull request reviews and issue-to-PR runs. | Shell |
